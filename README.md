# kempo-blog

A blog for kempo cms: posts with categories, tags, authors, comments and drafts.

## Page builder widgets

Two widgets go on any page built in the page builder, under **Blog**:

- **Recent posts** shows the latest published posts. Its settings are the number of posts, and a category or tag to limit them to.
- **Post list** shows published posts a page at a time. Its settings are a category, tag or author to limit them to, and the posts per page.

Neither shows drafts, and neither can be set to show them.
